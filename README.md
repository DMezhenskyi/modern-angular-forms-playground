# Modern Angular Forms Workshop

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 22.0.0-rc.0.

## Dependencies installation

If you use pnpm run: `pnpm install` (preferred)
If you use npm run: `npm install`

## Development server

To start a local development server, run:

(preferred)

```bash
pnpm start
```

or

```bash
npm run start
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## DevContainer

The project contains a configured devcontainer which provides a container with pre-setup node.js, pnpm, etc. To run project in dev container you need to start Docker Desktop on your computer and in Vs Code press `CMD+SHIFT+P` and choose `Dev Containers: Reopen in Container`. Dev container automatically runs `pnpm install` so you don't have to install npm dependencies manually.
